SETAKO VEDASTE PORTFOLIO WEBSITE

Files:
- index.html: portfolio content and sections
- style.css: black, red, and white visual design
- script.js: responsive mobile navigation and copyright year
- assets/setako-vedaste.jpeg: supplied portrait photograph

How to preview:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Keep the assets folder alongside index.html.

Before publishing:
- Confirm the personal contact details you want displayed and update the contact section.
- Review the project summaries and links. The portfolio projects are based on public GenerativeTek website information and should be adjusted to accurately reflect your individual contribution.
- Upload all files and the assets folder to your web host (for example, public_html).

Google Fonts are loaded online; local fallback fonts are included.
